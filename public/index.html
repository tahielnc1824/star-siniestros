Términos de Uso

      
    

    

      
Última actualización: 2 de octubre de 2026.

      
1. Objeto del servicio

      
STAR Siniestros es una herramienta digital de asistencia para la gestión de siniestros de seguros. Permite organizar relatos, generar observaciones, elaborar croquis orientativos y analizar información de pólizas mediante herramientas automatizadas e inteligencia artificial.

      
2. Alcance profesional

      
La plataforma funciona como herramienta de apoyo. Sus resultados no constituyen asesoramiento jurídico, dictamen de cobertura, liquidación de siniestros ni decisión de una compañía aseguradora. El usuario debe revisar la información antes de utilizarla profesionalmente.

      
3. Cuentas y acceso

      
Cada usuario es responsable de la confidencialidad de sus credenciales y de las operaciones realizadas desde su cuenta. STAR Siniestros puede habilitar, limitar, suspender o finalizar accesos cuando existan incumplimientos, vencimientos, falta de pago, uso abusivo o riesgos de seguridad.

      
4. Usos y límites

      
El acceso puede estar sujeto a una cantidad determinada de usos por período. Un uso se computa cuando una operación de inteligencia artificial se completa correctamente. Los límites, renovaciones y vencimientos son administrados según las condiciones acordadas con cada usuario.

      
5. Uso permitido

      
El usuario se compromete a utilizar la plataforma de forma lícita, profesional y de buena fe. No debe intentar vulnerar la seguridad, automatizar solicitudes abusivas, compartir accesos de forma no autorizada ni utilizar la plataforma para alterar, ocultar o inventar hechos de un siniestro.

      
6. Información ingresada

      
El usuario es responsable de contar con una base legítima para ingresar información personal o documentación de asegurados, terceros u otras personas. Debe evitar incorporar datos innecesarios para la finalidad del análisis.

      
7. Disponibilidad

      
Se procura mantener el servicio disponible y operativo, pero pueden existir interrupciones por mantenimiento, fallas de proveedores, actualizaciones o causas fuera del control razonable de STAR Siniestros.

      
8. Propiedad intelectual

      
La aplicación, su diseño, lógica, marca, interfaz y componentes propios pertenecen a sus titulares. El usuario conserva la responsabilidad sobre la información que incorpora y sobre el uso de los resultados obtenidos.

      
9. Limitación de responsabilidad

      
La plataforma puede producir resultados incompletos o inexactos. El usuario debe aplicar criterio profesional y verificar especialmente coberturas, exclusiones, datos de póliza, responsabilidades y cualquier información relevante antes de actuar.

      
10. Cambios

      
Estos términos pueden actualizarse cuando cambien el servicio, sus funciones o las condiciones comerciales. La versión vigente será la publicada dentro de la plataforma.

      
11. Legislación aplicable

      
El servicio se ofrece desde la República Argentina y estos términos se interpretan conforme a la normativa argentina aplicable.

    


    

      
Última actualización: 2 de octubre de 2026.

      
1. Qué información tratamos

      
Podemos tratar el email de la cuenta, datos técnicos de acceso y consumo, y la información que el usuario decide ingresar para realizar un análisis, incluyendo relatos de siniestros, daños y archivos de póliza.

      
2. Para qué se utiliza

      
La información se utiliza para autenticar usuarios, prestar las funciones de la plataforma, controlar límites de uso, administrar accesos, prevenir abusos, resolver errores y mejorar la operación del servicio.

      
3. Contenido de siniestros y pólizas

      
STAR Siniestros no ofrece un historial permanente de los análisis realizados. El contenido ingresado se procesa para responder la solicitud en curso. Las solicitudes enviadas a OpenAI se realizan con almacenamiento de respuestas desactivado mediante store:false.

      
4. Proveedores tecnológicos

      
Para operar el servicio se utilizan proveedores tecnológicos, entre ellos Supabase para autenticación y gestión de cuentas, Render para infraestructura, Resend para correos transaccionales y OpenAI para funciones de inteligencia artificial. Estos proveedores procesan información únicamente en la medida necesaria para prestar sus respectivos servicios.

      
5. Datos de cuenta y consumo

      
Se conservan los datos necesarios para gestionar la cuenta, su habilitación, vencimiento, límites y cantidad de usos. Esta información puede mantenerse mientras la cuenta esté activa y durante el tiempo razonablemente necesario para fines administrativos, de seguridad o cumplimiento.

      
6. Seguridad

      
Se aplican medidas razonables para restringir el acceso administrativo, proteger credenciales y evitar usos no autorizados. Ningún sistema conectado a Internet puede garantizar seguridad absoluta.

      
7. Derechos del usuario

      
El titular de los datos puede solicitar, según corresponda, acceso, actualización, rectificación o eliminación de información personal tratada por la plataforma, conforme a la normativa argentina aplicable.

      
8. Datos de terceros

      
Cuando un usuario carga información de asegurados, terceros o cualquier otra persona, es responsable de utilizar únicamente la información necesaria y de contar con una base legítima para su tratamiento.

      
9. Cambios en esta política

      
Esta política puede actualizarse para reflejar cambios técnicos, funcionales, comerciales o normativos. La versión vigente será la publicada dentro de STAR Siniestros.
